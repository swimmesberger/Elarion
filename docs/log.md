# Update log

## 2026-11-23

* **Creation**: [ADR-0106](decisions/0106-upload-policies-choose-the-staging-limits.md) — an upload names a policy that chooses its staging limits and runs a check before the body is read, after an application kept its own upload routes for 100 MB e-mail imports; the upload endpoints set the request's body-size limit to their cap; the [glossary](../GLOSSARY.md) gained *upload policy*.
* **Update**: [ADR-0098](decisions/0098-streamed-files-for-http-only-endpoints.md) gained an amendment: ElarionStreamedFile.Deferred decides the file after the pipeline and may refuse with an AppError before its first byte, so an attachment found only while parsing a stored message is read once; the [glossary](../GLOSSARY.md) entry *streamed file* mentions it.
* **Update**: [ADR-0095](decisions/0095-one-resource-rule-for-list-point-check-and-complement.md) gained an amendment: QueryAuthorizers.UnlessClaim, a negated claim gate that withdraws an alternative from sessions carrying a claim (viewing the application as another user), read in both directions.
* **Update**: [ADR-0095](decisions/0095-one-resource-rule-for-list-point-check-and-complement.md) gained an amendment: WhereAuthorizedForAll lists the principals who may access every row of a selection, from the same relation, and nobody for an empty selection.
* **Update**: [ADR-0095](decisions/0095-one-resource-rule-for-list-point-check-and-complement.md) gained an amendment: QueryAuthorizers.Via lifts an owner type's rule to the rows that point at its owners, through a navigation or a joined set, in both directions, after an application hand-wrote the inverse of an "assigned to a record the caller may read" rule.
* **Update**: [ADR-0101](decisions/0101-a-decision-required-answer.md) has an amendment: `Unanswered<TOption>` counts only a declared option and the untyped `Unanswered` only a confirmation, so a handler never skips an item answered with an undeclared option.
* **Update**: [ADR-0105](decisions/0105-uploaded-files-are-handler-parameters.md) gained an amendment: upload refusals carry the limit as typed data and are implied by `[UploadLimits]`, a member accepts file extensions, the generated `uploadFile` checks the limits of a named method member, and `DeleteAsync` on the PostgreSQL store is documented to save the shared `DbContext`, after an application that moved its imports to uploaded files reported these gaps; the glossary's *upload limits* include file extensions and typed refusals.

## 2026-11-22

* **Update**: [ADR-0102](decisions/0102-rules-are-expressions-composed-once.md) gained an amendment: a rule takes one to four inputs, the expander and the rule check recognize every arity without a list, and Expr.Expand takes a lambda directly so a helper needs no typed local.
* **Update**: [ADR-0101](decisions/0101-a-decision-required-answer.md) gained an amendment: the schema narrows a request's decisions member to its declared answers, the generated client exposes decisionQuestion and answerDecision (withDecisions takes the client or a call function), and DecisionAnswer gains Confirming and Choosing.
* **Update**: [ADR-0100](decisions/0100-the-schema-exports-constants-presets-and-limits.md) accepted and implemented: typed limits, declared upload limits, request presets, sort keys and client constants in the schema and the generated client; [ADR-0105](decisions/0105-uploaded-files-are-handler-parameters.md) amended for the declared limits; glossary gains upload limits, request preset and client constants
* **Update**: [ADR-0001](decisions/0001-event-transaction-phase.md) and [ADR-0003](decisions/0003-decorator-attachment-predicates.md) gained an amendment: the core package ships the opt-in TransactionDecorator, and the preview decorator of ADR-0104 is the one built-in owner of a unit of work.
* **Update**: [ADR-0102](decisions/0102-rules-are-expressions-composed-once.md) now records UseElarionRuleCheck, the EF Core interceptor that refuses a query with an unexpanded rule.
* **Update**: [ADR-0101](decisions/0101-a-decision-required-answer.md) is accepted and implemented, with per-item decisions, answers as one list of code, item and option, and options as camel-cased enum members; the glossary gained *decision*.
* **Creation**: [ADR-0103](decisions/0103-one-permission-decision-and-members-visible-by-permission.md), one permission decision (IPermissionChecker) shared by the gate, handler code and response members visible by permission ([VisibleWith]); glossary terms Permission checker and Member visible by permission.
* **Update**: [ADR-0102](decisions/0102-rules-are-expressions-composed-once.md) is accepted and implemented: rules over two inputs replace the proposed tuple-input rule (expression trees cannot contain tuple literals), Expr gained Inline, AnyOf, AllOf and Not, and the consequences now say what EF Core does when Expand is forgotten; the [glossary](../GLOSSARY.md) gained *rule*.
* **Creation**: [ADR-0104](decisions/0104-previewable-commands.md) — a previewable command is one handler that previews (runs, reports, rolls back) and commits only the outcome it previewed, from the preview/commit handler pairs of a consuming application; the [glossary](../GLOSSARY.md) gained *previewable command*.
* **Creation**: [ADR-0105](decisions/0105-uploaded-files-are-handler-parameters.md) — a handler takes a staged upload as an UploadedFile and reads, keeps or discards it only through IUploadedFiles, which answers the caller's own pending upload and nothing else; the [glossary](../GLOSSARY.md) gained *uploaded file*.
