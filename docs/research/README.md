# Research notes

Notes that summarise outside material for Elarion: vendor documentation, source code of other systems, a
profiling run, an investigation by the `research` skill. One file per question, named `YYYY-MM-DD-topic.md`,
with `type: Research note`, the URLs it rests on under `sources:` in the frontmatter or a `Sources` heading,
and an entry in [../index.md](../index.md). A research note is secondary: when it disagrees with its sources,
the sources win. A note that is the input of a decision says so and links the ADR; the ADR links back. Rules
in [../guide.md](../guide.md).
